# KER Ready Reckoner & Document AI Website
കേരള എജ്യുക്കേഷൻ റൂൾസ് (KER) അടിസ്ഥാനമാക്കിയുള്ള സമ്പൂർണ്ണ AI ചാറ്റ്ബോട്ട് & ഡോക്യുമെന്റ് അനലൈസർ വെബ് ആപ്ലിക്കേഷൻ.

---

## പ്രത്യേകതകൾ (Key Features)
1. **KER റൂൾസ് അസിസ്റ്റന്റ്:** KER അധ്യായങ്ങളും (Chapters), ചട്ടങ്ങളും (Rules) ഉദ്ധരിച്ചുകൊണ്ടുള്ള കൃത്യമായ മറുപടികൾ.
2. **ലൈവ് PDF അപ്‌ലോഡ് (Document Analyzer):** സ്വന്തം സർക്കുലറുകളോ, ഗവൺമെന്റ് ഓർഡറുകളോ, KER പിഡിഎഫുകളോ അപ്‌ലോഡ് ചെയ്ത് ചോദ്യങ്ങൾ ചോദിക്കാം.
3. **മലയാളം & ഇംഗ്ലീഷ് പിന്തുണ:** മലയാളത്തിലും മംഗ്ലീഷിലും ഇംഗ്ലീഷിലും സുഗമമായി ആശയവിനിമയം നടത്താം.
4. **സുരക്ഷിതത്വം & നിയന്ത്രണം:** തെറ്റായ വ്യാഖ്യാനങ്ങൾ നൽകാതിരിക്കാൻ കർശനമായ സിസ്റ്റം പ്രോംപ്റ്റുകൾ (Hallucination Prevention).
5. **ആധുനിക UI/UX:** മൊബൈലിലും കമ്പ്യൂട്ടറിലും ഒരുപോലെ പ്രവർത്തിക്കുന്ന റെസ്‌പോൺസീവ് ഡിസൈൻ.

---

## പ്രാദേശികമായി റൺ ചെയ്യുന്ന വിധം (Local Run)

1. **Python ഇൻസ്റ്റാൾ ചെയ്യുക:** നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ Python 3.9 അല്ലെങ്കിൽ അതിനു മുകളിലുള്ള വേർഷൻ ഉണ്ടായിരിക്കണം.
2. **ഡിപെൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യുക:**
   ```bash
   pip install -r requirements.txt
   ```
3. **API Key സജ്ജീകരിക്കുക:**
   - [Google AI Studio](https://aistudio.google.com/) സന്ദർശിച്ച് ഒരു സൗജന്യ API Key എടുക്കുക.
   - `.env.example` ഫയൽ കോപ്പി ചെയ്ത് `.env` എന്ന് പേരുമാറ്റി അതിൽ API Key നൽകുക:
     ```env
     GEMINI_API_KEY=your_actual_key_here
     ```
   *(അല്ലെങ്കിൽ വെബ്‌സൈറ്റ് തുറന്ന ശേഷം സെറ്റിങ്സിൽ നേരിട്ടും API Key നൽകാം).*
4. **വെബ്‌സൈറ്റ് ആരംഭിക്കുക:**
   ```bash
   uvicorn main:app --reload
   ```
   ഇപ്പോൾ ബ്രൗസറിൽ `http://127.0.0.1:8000` തുറന്നാൽ സൈറ്റ് കാണാം.

## വെബ്‌സൈറ്റ് പബ്ലിക് ഡൊമൈനിൽ സൗജന്യമായി ഹോസ്റ്റ് ചെയ്യുന്ന വിധം (Hosting Guide)

### ഓപ്ഷൻ 1: Render.com (ഏറ്റവും എളുപ്പമുള്ള വഴി - 100% സൗജന്യം)
1. ഈ പ്രൊജക്റ്റ് ഫോൾഡറിലെ ഫയലുകൾ ഒരു പുതിയ **GitHub Repository**-യിലേക്ക് പുഷ് ചെയ്യുക (ഉദാ: `ker-ai-assistant`).
2. [Render.com](https://render.com) സന്ദർശിച്ച് സൗജന്യ അക്കൗണ്ട് ഉണ്ടാക്കുക.
3. **New +** ക്ലിക്ക് ചെയ്ത് **Web Service** തിരഞ്ഞെടുക്കുക.
4. നിങ്ങളുടെ GitHub Repo ലിങ്ക് ചെയ്യുക.
5. താഴെ പറയുന്ന വിവരങ്ങൾ നൽകുക:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
6. **Environment Variables**-ൽ:
   - Key: `GEMINI_API_KEY`
   - Value: `നിങ്ങളുടെ Gemini API Key`
7. **Create Web Service** അമർത്തുക. ഏതാനും മിനിറ്റുകൾക്കകം സൗജന്യ ലിങ്ക് (ഉദാ: `https://ker-assistant.onrender.com`) ലഭിക്കും!

### ഓപ്ഷൻ 2: കസ്റ്റം ഡൊമെയ്ൻ നൽകാൻ (Custom Domain)
- `www.kerhelp.in` അല്ലെങ്കിൽ `www.kereducation.org` പോലുള്ള ഡൊമൈനുകൾ Namecheap, GoDaddy, അല്ലെങ്കിൽ Hostinger വഴി വാങ്ങുക (പ്രതിവർഷം ഏകദേശം ₹500 - ₹800).
- Render-ലെ **Settings -> Custom Domains**-ൽ പോയി വാങ്ങിയ ഡൊമൈൻ നൽകുക.
- അവിടെ ലഭിക്കുന്ന DNS CNAME റെക്കോർഡുകൾ ഡൊമൈൻ പ്രൊവൈഡറുടെ പാനലിൽ ആഡ് ചെയ്യുക.
