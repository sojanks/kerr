കേരള എജ്യുക്കേഷൻ റൂൾസുമായി (KER) ബന്ധപ്പെട്ട ഏത് സംശയങ്ങളും നിങ്ങൾക്ക് ഇവിടെ ചോദിക്കാം. കൂടാതെ നിങ്ങളുടെ പക്കലുള്ള KER പിഡിഎഫുകളോ ഉത്തരവുകളോ ഇടത് വശത്ത് അപ്‌ലോഡ് ചെയ്തും ചോദ്യങ്ങൾ ചോദിക്കാവുന്നതാണ്.

Google Gemini API Key

ഗൂഗിൾ എഐ സ്റ്റുഡിയോയിൽ നിന്നും (aistudio.google.com) സൗജന്യമായി ലഭിക്കുന്ന API Key ഇവിടെ നൽകുക. ഇത് നിങ്ങളുടെ ബ്രൗസറിൽ മാത്രമേ സൂക്ഷിക്കപ്പെടുകയുള്ളൂ.
